# Трекер привычек

REST API для создания и отслеживания полезных привычек. Пользователи могут создавать собственные привычки, просматривать публичные привычки и получать напоминания о выполнении привычек в Telegram.

## Расположение проекта

### Забрать проект можно так

`git clone https://github.com/vmrmozg138/Habits-CP5-.git`

## Основной функционал

- Реализована кастомная модель пользователя с авторизацией по email.
- Настроена JWT-аутентификация.
- Создана модель привычки с необходимыми полями и бизнес-правилами валидации.
- Реализован CRUD API для работы с привычками.
- Настроены права доступа: пользователь может управлять своими привычками, а публичные привычки доступны для просмотра другим пользователям.
- Добавлена пагинация.
- Реализована интеграция с Telegram для отправки напоминаний.
- Подключены Celery и Redis для выполнения фоновых задач.
- Настроен Celery Beat для запуска задач по расписанию.
- Написаны автоматические тесты. Общее покрытие кода — 95%.

## Установка и запуск проекта

### 1. Клонировать репозиторий

`git clone <ссылка-на-репозиторий>`

Перейти в папку проекта:

`cd <название-папки-проекта>`

### 2. Создать виртуальное окружение

`python -m venv venv`

Активировать виртуальное окружение:

Windows:

`venv\Scripts\activate`

Linux / macOS:

`source venv/bin/activate`

### 3. Установить зависимости

`pip install -r requirements.txt`

### 4. Настроить переменные окружения

Создать файл `.env` и указать необходимые настройки проекта: параметры базы данных, секретный ключ Django, настройки Redis и Telegram Bot Token.

### 5. Выполнить миграции

`python manage.py migrate`

### 6. Запустить Django

`python manage.py runserver`

### 7. Запустить Celery Worker

`celery -A config worker -l INFO`

### 8. Запустить Celery Beat

`celery -A config beat -l INFO`

Перед запуском Celery необходимо убедиться, что Redis запущен и доступен по адресу, указанному в настройках проекта.
